# RAG Benchmark Platform

A modular Retrieval-Augmented Generation (RAG) benchmark platform built from scratch in Python.

## Features

- PDF Loader
- Text Normalization
- Multiple Chunking Strategies
- Embedding Models
- FAISS Vector Store
- Dense Retrieval
- Prompt Builder
- LLM Integration (Coming Soon)
- Evaluation & Benchmarking (Coming Soon)

## Tech Stack

- Python
- Sentence Transformers
- FAISS
- NumPy
